Running this for the first time? A plain static server can't write files, so this page needs the small local helper server instead: python3 scripts/local_server.py from the mustwatch-web folder, then open the site at http://127.0.0.1:8000/ and click Access in the top nav to log in. It only listens on your machine — never on the network — and never pushes or publishes anything.
